# Contributing

Contributions, bug reports, and improvement ideas are welcome.

## Before submitting changes

- Keep changes focused and clearly explained.
- Add or update tests when behavior changes.
- Run `backend/.venv/bin/pytest -q`.
- Run `npm run build` inside `frontend`.

## Privacy

Never commit `.env` files, API keys, private documents, local data, model weights, or credentials.

## Pull requests

Describe what changed, why it was needed, and how it was tested.
